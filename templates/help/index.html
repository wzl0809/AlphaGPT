从注册到生成第一个量化信号的完整路径

账户与登录

注册 · 登录 · 找回密码 · 版本更新

进入所有量化功能前的必经入口。注册、登录、找回密码、客户端版本更新都在这里完成，全部免费开放。新用户注册即赠送算力。

核心功能
白名单注册
支持 QQ/网易/Gmail/Outlook 等主流邮箱域名，发码前先校验域名
找回密码
邮箱收重置码（24h 一次、30 分钟有效），改密即吊销全部设备会话
更新中心
版本过旧被服务端拒登时自动跳转，提供多渠道下载，数据不丢失
亮/暗主题
登录页右上角一键切换，全站生效并记忆
操作流程
注册新账号 首次使用
1
打开客户端，登录页点「没有账号？去注册」
2
选择邮箱域名（下拉常用域名），或在最底部选「其他」手输完整邮箱
3
点「发送验证码」：首次直接发送；若提示「正在验证，约 1 秒」是 PoW 防滥用，稍等即可
4
到邮箱查收 6 位验证码（注意翻一下垃圾邮件/广告邮件分类）
5
输入验证码、用户名（输入时自动查重，绿色 √ 表示可用）、设置密码
6
点「确认注册」，成功后自动跳回登录页，用邮箱 + 密码登录
小贴士
  • 只支持主流邮箱域名，非白名单域名（选「其他」手输）会被拦截
  • 验证码按钮成功后会灰掉 10 分钟，关闭页面再打开仍在冷却中
版本过低被拒登后更新 升级客户端
1
旧版登录被自动跳转到「更新中心」，顶部红框提示需更新到最新版
2
在「下载地址」选一个渠道（带「推荐」标的为官方主推），点「下载」
3
系统托盘 AlphaGPT 图标右键 → 退出，完全关闭旧客户端（直接点 × 可能仍在后台）
4
解压新版覆盖旧目录，启动新版，点底部「我已安装新版，重新检测」
5
检测通过后跳回登录页，用原账号登录
小贴士
  • 找不到托盘图标就用 Ctrl+Shift+Esc 任务管理器结束 AlphaGPT / pythonw 进程
  • 更新不会丢任何数据：账号、算力、自建公式、训练记录全部保留
{# ═══════════ 首页 ═══════════ #}

首页仪表盘

一屏看全账户状态与 A 股大盘温度

登录后的默认落地页。左侧是你的账户信息卡（等级、算力、版本），中间是情绪仪表盘（涨跌家数、涨停跌停、成交额），右侧是 AI 评述与市场新闻。打开瞬间渲染本地缓存秒进，点「刷新大盘数据」才强拉最新行情。

核心功能
公告横幅
紧急/重要/普通三档，多条每 5 秒自动轮播
个人信息卡
等级徽章、头衔、算力、版本、用户 ID
情绪仪表盘
0-100 分半圆指针，分红(偏弱)/黄(震荡)/绿(强势)，附打分依据
主要指数表
上证/深成/创业板涨跌幅 + 涨停/跌停家数 + 两市成交额
AI 评述
配置 DeepSeek Key 后：结论 + 风险 + 利好 + 趋势预测 + 操作建议
市场新闻
配置 Tavily Key 后：当日中文财经新闻 + 新闻情绪（涨/跌/平）
板块领涨/领跌
行业板块涨跌前 5 名，快速发现当日热点与弱势
刷新大盘数据
一键强拉行情→评述→新闻（串行），防连点，失败保留旧数据
操作流程
刷新今日大盘（日常看盘）
1
点击页面上方「刷新大盘数据」按钮
2
等待按钮显示「刷新中…」（行情秒级，AI 评述首次约 10-20 秒，新闻 5-10 秒）
3
先看仪表盘指针与温度档（偏弱/震荡/偏暖/强势）
4
读下方「打分依据」列表（上涨家数占比、指数涨跌幅、涨停跌停净额、成交额）判断分数合理性
5
向下看主要指数表与板块领涨/领跌定位当日热点；阅读 AI 评述的结论、风险与操作建议
小贴士
  • 首次打开首页是「零网络」的——只读本地缓存秒进，新鲜度完全靠你点这一下「刷新大盘」
  • 盘中（9:30-11:30 / 13:00-15:00）行情缓存 3 分钟，非交易时段统一 30 分钟，但前台都不会自动刷新
  • 出现橙色「实时行情获取受限」提示时，分数是按剩余维度估算的，请结合实盘核实
情绪分数
0-100 综合分，由上涨家数占比(权重 0.45) + 指数平均涨跌幅(0.35) + 涨跌停结构(0.20) 加权得出。≥70 强势、≥55 偏暖、≥40 震荡、<40 偏弱，只看分档即可
两市成交额
≥15000 亿为高活跃、≥9000 亿中等活跃、更低为缩量观望。放量上涨配合强势分数更可信
趋势预测
AI 给出强烈看多/看多/震荡/看空/强烈看空，与情绪分数方向应基本一致，背离时以仪表盘硬指标为准
研究倾向
倾向参与/继续/观望/降低关注/回避，仅作研究参考不构成投资建议，务必同时阅读风险清单
看不到 AI 评述或新闻？这两块依赖你在「系统设置」配置 DeepSeek / Tavily 的 API Key，配置后即可使用，对所有用户免费开放。
{# ═══════════ 系统设置 ═══════════ #}

系统设置

账号 · 密钥 · 硬件 · 存储

平台的控制中心：改密码、配置 AI 与数据源 API Key、查看本机硬件、清理训练产生的报告和断点。配一次全局生效，是让平台跑起来、跑得稳、不占满磁盘的关键页。

核心功能
个人信息维护
修改手机/QQ/微信（邮箱与昵称锁定不可改）
API Key 加密管理
DeepSeek 或任意 OpenAI 兼容端点，掩码预填、不动即留、清空即删
修改密码 + 全设备下线
成功后服务端吊销全部会话，本地立即登出强制重登
硬件识别报告
CPU/内存/系统/Python 版本 + 显卡型号与显存（NVIDIA 可识别）
性能全局调优
数据源并发 + 运算核心数，配一次所有训练生效
存储清理
reports（报告/PNG）与 checkpoints（断点）分页批量删除
操作流程
配置 AI 大模型 Key（开通研究仪表盘）
1
进入「系统设置 → API Key 管理」卡片
2
二选一：填 DeepSeek（sk- 开头），或 OpenAI 兼容端点（接口地址 + 模型名 + Key 三件套全填）
3
（可选）填 Tavily 用于新闻情绪、Tushare 作为数据源兜底
4
点「保存」，绿色提示显示各家开通状态；去量化页或首页验证 AI 是否生效
小贴士
  • OpenAI 兼容端点三件套必须全填（如智谱：地址 + glm-4 + Key），漏填模型名该服务商会被跳过
  • Ollama/vLLM 本地部署时，Key 随便填一个字即可通过校验
  • 输入框预填的是掩码点，不动它就是保留；想删除就把框清空再保存
运算核心数
CPU 线程数 0~64（0=自动）。仅 CPU 训练生效，有 NVIDIA GPU 时默认走 CUDA，此值不生效
加密标注
「Fernet（cryptography）」= 强加密（推荐）；「XOR+Base64」= 弱保护，建议装 cryptography 库
换电脑/改计算机名会解密失败：API Key 加密密钥由 FLASK_SECRET + 计算机名派生，机器名一变旧密钥就打不开，需在 API Key 管理里重新输入全部 Key。
改密会让自己下线：修改密码后服务端吊销该账号全部会话（含当前设备），需用新密码重新登录——这是安全设计，怀疑被盗时改一次密码即可让所有设备下线。
{# ═══════════ 训练系统 ═══════════ #}

训练系统

AI 自动挖掘量化因子公式（平台核心）

让 AI 在历史数据上自动搜索出一个在历史回测中相对基准有超额表现的量化因子公式，并给出样本外夏普、回撤、胜率等历史回测指标，训练完一键存进公式库。公式由 AI 自动生成、无法手写，只能来自训练/购买/接力/悬赏四类来源。

训练流水线：数据 → 因子 → 生成 → 强化优化 → 样本外验证
核心功能
参数对照表
9 大参数组 40+ 参数，每个「?」悬停弹深色浮层说明
种子策略 A-F
混沌/网格/黄金分割/极致复现/区间扫描/AI 探索
训练控制台
开始/停止/清空 + 分段变色进度条 + 状态指示灯
硬件实时监控
每 3 秒刷新 CPU/内存/GPU/显存占用，结束自动停
实时日志框
逐行推送自动滚动，含参数摘要与完成提示
结果分类卡
按 test_sharpe 分劣质(红)/普通(灰)/优质(绿)三档，附基准图
操作流程
训练你的第一个公式 基础流程
1
进入「训练系统」，硬件监控先拉一次当前占用
2
在「训练数据」组填写「标的代码」（如 601963 或 510050 ETF），必填、默认留空
3
确认起止日期（开始默认 2021-01-01，结束默认当天，建议至少 2~3 年数据）
4
按需调整「多轮寻优」轮数（≥20 计有效训练）；种子策略首次用默认 A 混沌探索
5
点「开始训练」，进度条推进、日志实时刷新、硬件占用每 3 秒更新
6
完成后看「结果分类卡」的 test_sharpe、年化、回撤、胜率、Calmar 和基准图
7
「优质」或「普通」时点「保存到公式库」入库；「劣质」按钮自动禁用
小贴士
  • 代码必填且默认留空，否则会提示「请先填写标的代码」不发送请求
  • 训练期间顶部红色警示条提示不要关闭/刷新页面——断网或关页面会中断训练浪费算力
  • 跑常见配置（迭代300、Batch1024、寻优20轮）通常要数小时，机器高负载发热，注意散热
  • 训练中可随时点「停止」中止，系统会自动清理本股票的半成品断点
复现与对比实验 进阶
1
先用 A/E 跑一版公式，记下 test_sharpe 和系统回填的真实种子作为基准
2
把种子策略切到「D 极致复现」，右侧变成手动种子输入框，填入上次的种子
3
保持代码/日期/迭代/Batch/寻优轮数完全一致，再次开始训练对比指标
小贴士
  • 只有 D 能精确复现；A/B/C/E 每次种子都变，适合探索不同方向
  • 复现实验可排查「公式是真有信号还是运气好」——换种子还能跑出相近收益才算稳健
训练结果指标（产出）
test_sharpe 样本外夏普
决定公式分类档位：≤0.4 劣质 / 0.4~1.5 普通 / ≥1.5 优质。优先取样本外(OOS)值更贴近实盘；越大越好但须配合回撤看
max_dd 最大回撤
从净值最高点到后续最低点的最大跌幅。越小越稳，20%以内算稳健，超40%风险偏高。高夏普+低回撤=理想
ann_ret 年化收益
把回测总收益按252交易日复利折算成一年。正值赚负值亏，基于历史不代表未来
win_rate 胜率
样本外区间开仓后盈利次数占开仓总次数比。不是每日方向命中率（命中率见信号页）
训练数据组（所有用户可调）
标的代码
6位代码。个股如601963；ETF如510050/510300。引擎自动获取该标的历史行情（OHLCV+两融）
开始日期
训练数据起始日。建议5年以上保证RL样本量；不少于1年即可训练，太短效果可能不稳定
手续费率
单边综合手续费（默认万分之四）。设高惩罚高频交易倾向低频策略；设0不考虑成本（不真实）。A股综合约万分之3~8
多轮寻优
auto_optimize_runs。=1单次训练；>1每轮不同种子取最优。≥20计有效训练。50为推荐上限
训练微调组
持仓周期(天)
固定持仓N天后平仓，未考虑止损止盈。1-2天适合短线；5-10天捕捉中长趋势但回撤大。不建议>10
迭代次数
train_iterations。≥300计有效训练。更多迭代更充分收敛但耗时线性增长。GPU上300轮约10-30分钟
Batch 大小
每轮生成公式数量。≥1024计有效训练。更大→梯度更平滑但显存高；显存不足时调小至512或256
公式长度
max_seq_len，公式token上限。控制表达式树深度。过长（>15）易过拟合；过短（<6）表达力不足。推荐8-14
噪声测试
对最佳公式加高斯噪声扰动测鲁棒性——加噪后失效说明过拟合（脆弱）。默认20次
奖励组
奖励模式
sharpe=夏普复合奖励（推荐）；winrate=纯胜率（忽略收益大小，高胜率≠赚钱，不推荐）
奖励偏好
balanced=均衡(0.4/0.3/0.3)；stable=稳健(夏普优先)净值更平滑回撤小；aggressive=进攻(收益优先)回撤大；custom=自定义三权重
夏普/收益/盈亏比权重
仅custom模式生效，三者之和应为1.0。夏普权重高→追求稳定盈利；收益权重高→追求绝对回报
训练优化组
归一化奖励
batch内z-score归一化——牛市不因涨盲目奖励、熊市不因跌惩罚。推荐True
复杂度惩罚
complexity_alpha。惩罚=α×(公式长度/最大长度)。越大→公式越短（简洁=泛化好）；α=0可能冗长过拟合。推荐0.02-0.05
熵系数
entropy_coef。鼓励策略网络探索防过早收敛到次优公式。越大→探索越强但收敛慢；推荐0.001-0.01
固定持仓
True=固定持仓期收益（无未来信息泄露，回测真实）；False=自适应退出（可能利用未来信息过拟合）。强烈建议True
PPO+GAE 组（强化学习核心）
PPO Epochs
每批数据重复利用次数（默认3）。更多=数据利用充分但过拟合风险增。推荐2-4
PPO 裁剪
clip_eps，限制策略更新幅度防训练崩溃。0.1=保守小步稳但慢；0.3=激进大步快但不稳。标准0.2通常不改
GAE Gamma
折扣因子γ（默认0.99）。越接近1越看重长远收益（远期奖励几乎不折减）。推荐0.95-0.995
GAE Lambda
偏差-方差权衡λ（默认0.95）。越大越信任实际收益（高方差低偏差）；越小越信任价值估计（低方差高偏差）。推荐0.9-0.97
因子选择组
自动选前K个
auto_select_top_k。IC推荐选IC最高的K个因子参与训练。K越大表达力越强但过拟合风险增；推荐7-14
IC 阈值
|IC|≥0.03视为有弱信号纳入候选。设高(0.05)只留强信号；设低(0.01)保留更多但含噪声
IC t值阈值
|t|≥2约95%置信因子IC不为零（非随机波动）。数据越长t值越容易达标(SE≈1/√N)。设低(1.0)保留更多但可能不显著
滚动IC窗口
用最近N天算IC稳定性(ICIR/t值)。太短(20天)噪声大；太长(250天)反应慢。推荐40-120
去冗余(>0.7)
自动剔除与其他已选因子相关系数>0.7的冗余因子（如RSI14和WR_DIFF高度相关→只留IC更高的）。防共线性提升泛化。推荐True
早停/效率组
验证间隔
