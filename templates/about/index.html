核心技术与先进性

五个维度的工程纵深，构成「科学、可信、安全、高效」的量化闭环

Transformer + PPO 双引擎因子自进化

遗传编程 × 深度强化学习的混合范式

策略网络自回归生成波兰式数学公式，由 19 因子与 12 算子组合；经 GPU 并行解析与向量化回测后，用 PPO+GAE 近端优化迭代夏普与胜率。比传统遗传编程收敛更快，比纯神经网络更具可解释性。

PPO clip=0.2 γ=0.99 λ=0.95 GAE 优势估计 torch.jit 编译
科学依据：Transformer 学习公式语法，RL 提供搜索方向，两者优势互补。

四引擎 LLM 路由 + 六维防幻觉仪表盘

schema-as-prompt + 数据一致性硬约束

支持 DeepSeek / GLM / 通义 / OpenAI 兼容四路大模型智能路由，任一限流即无缝切换。输出经 Pydantic 结构化校验的六维研究仪表盘，叠加硬护栏（主力流出禁参与、获利盘>85% 标抛压），从源头遏制 LLM 幻觉。

自动 failover 指数退避重试 11+ 基本面字段 诚实降级标注
科学依据：用真实行情/资金/筹码数据（而非 LLM 记忆）作硬约束过滤器，结论可复现可追溯。

Fernet 认证加密 + Argon2 哈希纵深防御

从密钥到会话的全链路安全

API Key 与交易公式均经 Fernet 认证加密（AES-128-CBC + HMAC-SHA256，Encrypt-then-Mac）落盘，公式支持 MultiFernet 密钥热轮换。账户密码采用 Argon2 内存硬哈希抗 GPU 暴破；JWT 双令牌 + 黑名单实现改密即一键吊销全部设备会话，叠加登录递增退避、hashcash PoW 与 HSTS/Secure Cookie 安全头。

Encrypt-then-MAC MultiFernet 密钥轮换 Argon2 内存硬哈希 JWT 黑名单吊销 6 级登录退避 hashcash PoW
科学依据：认证加密保证密文任一比特被篡改即被拒绝；内存硬哈希抗 ASIC/GPU 并行；密钥族设计杜绝单点泄露致存量密文可解。

科学方法论

一条从因子到信号的严谨流水线，系统性杜绝过拟合

因子筛选

Spearman IC + t 值双重显著性门槛

RL 训练

Transformer 生成公式，PPO 优化

样本外检验

6:2:2 划分，20% 严格 OOS 评估

鲁棒性

多种子寻优 + 高斯噪声扰动

诚实信号

新鲜度守卫 + 命中率实盘校验

因子显著性

|IC| ≥ 0.03 且 |t| ≥ 2（约 95% 置信）方纳入；剔除相关 >0.7 的冗余因子，避免多重共线性。

样本外诚实

test_sharpe 优先取 OOS 夏普，仅在取不到时回退训练期分数；训练期偏乐观，OOS 才贴近实盘。

鲁棒归一

训练集口径 median/MAD 鲁棒归一化 + 高斯噪声扰动测试，过滤极端值与运气，留下稳健信号。
